# TRAIN ME WRONG — Four-Front Survivor Command

네 개의 전장을 동시에 감시하며 가장 위험한 전선의 영웅을 직접 지휘하고, 나머지 영웅은
전투 AI에 맡기는 5분짜리 웹 서바이벌·전술 타워 디펜스 게임입니다. 모든 게임 상태와 AI는
브라우저 안에서 실행되며 외부 API나 API 키가 필요하지 않습니다.

## 핵심 루프

1. 2×2 지휘 화면에서 빙결 중계소, 용광 제련소, 네온 기록고, 생체 보존고를 동시에 감시합니다.
2. 전선을 클릭하거나 `1–4`를 눌러 한 영웅을 직접 조작합니다. 나머지 영웅은 계속 AI가 조작합니다.
3. 모든 전선의 처치 골드는 하나의 전쟁 자금으로 즉시 합산됩니다.
4. 공유 골드로 선택 영웅의 공격·방어를 강화하고 드론, 센트리, EMP 파일런, 회복·방벽 아이템을 구매합니다.
5. 영웅이 사망하면 해당 전선이 함락됩니다. 그 전선의 기존 및 신규 적은 인접 구역으로 이동하고 생존 전선의 침공 레벨이 상승합니다.
6. 5분 동안 한 곳 이상의 전선을 유지하면 철수에 성공합니다.

## 네 영웅

- `AEGIS / CRYO RELAY`: 빠르고 안정적인 단발 펄스 돌격 영웅
- `ROOK / EMBER FORGE`: 근거리 3연 산탄으로 군집을 정리하는 화력 영웅
- `NYX / NEON ARCHIVE`: 적 사이를 연쇄하는 전격 영웅
- `MOSS / VERDANT VAULT`: 관통 중탄과 기본 재생을 지닌 생존 영웅

## 조작

- `1–4` 또는 전선 클릭: 전선 확대 및 해당 영웅 직접 지휘
- `WASD` / 방향키: 선택 영웅 이동
- `Space`: 무적 시간이 포함된 대시
- `Q`: 구매한 센트리 설치
- `E`: 구매한 EMP 파일런 설치
- `Tab` / `Esc`: 네 전선 전체 상황판으로 복귀
- `B`: 전술 상점 열기·닫기
- 공격: 모든 영웅과 지원 장비가 자동 조준·사격

## 공유 골드와 상점

경험치와 스크랩은 사용하지 않습니다. 모든 적은 사망 즉시 공유 골드를 지급합니다. 상점은
전선이 확대된 상태에서 열 수 있고, 구매 대상은 현재 선택한 영웅입니다. 무기 코어, 반응
서보, 강화 장갑, 나노 수복은 반복 강화할 수 있으며, 윙맨 드론·센트리·EMP 파일런은 실제
투명 스프라이트를 사용하는 전투 개체로 등장합니다. 구급팩, 방벽 셀, 전선 동기화 수복도
공유 골드로 구매합니다.

## AI와 연쇄 침공

비선택 영웅은 가까운 위협과 사거리를 계산해 접근·후퇴·횡이동하고, 포위되면 대시하며,
해금된 설치 스킬도 위협 밀도에 맞춰 자동 사용합니다. 전선이 함락되면 그곳을 목표로 하던
적들의 목표 전선이 즉시 바뀌고 실제 2×2 전장 사이를 이동합니다. 함락 구역에서도 추가
병력이 발생해 인접 전선으로 이동하므로 한 영웅만 과도하게 강화하면 후반 난도가 급상승합니다.

## 에셋과 오디오

배우와 설치형 스킬은 `public/assets/survivor/` 아래의 프로젝트 전용 이미지입니다. 센트리,
EMP 파일런, 윙맨 드론은 이번 버전을 위해 신규 제작하고 크로마키 제거 후 투명 PNG로
정리했습니다. 회전·가속·감속·반동·대시 잔상·피격 플래시는 엔진에서 합성합니다. 효과음은
외부 음원 없이 `src/audio/sfx.js`에서 Web Audio로 실시간 합성합니다. 자세한 출처는
[`CREDITS.md`](./CREDITS.md)를 참고하세요.

배경음악은 사용자가 Suno AI로 별도 제작할 예정이며 현재 빌드에는 포함하지 않았습니다.
