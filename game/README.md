# TRAIN ME WRONG: OVERLOAD

`TRAIN ME WRONG: OVERLOAD`는 단 한 명의 전투원을 직접 이동시키고, 포인터로 사격 방향만
조준하는 브라우저 기반 오픈 아레나 생존 액션 게임입니다. 시작과 동시에 밀려드는 고정
물량 300기를 빠르게 쓸어내고, 전멸 직후 등장하는 거대 보스 `THE WRONG ENGINE`의 공격을
피하며 약점을 파괴하는 약 65~80초짜리 압축 런을 목표로 합니다.

## 한 판의 흐름

1. 전투 시작과 동시에 사방의 진입로에서 대규모 적 병력이 몰려옵니다. 이후 6초, 14초,
   23초 구간에는 경고 방송 뒤 추가 병력이 게이트에서 폭발적으로 투입됩니다.
2. 기본 무기는 포인터 방향으로 항상 자동 발사됩니다. 플레이어는 이동과 조준, 대시에
   집중해 적 무리를 한 줄로 모으거나 빈틈을 뚫습니다.
3. 적이 떨어뜨린 XP를 모으면 시작 후 약 6~10초 안에 첫 레벨업이 발생합니다.
4. 레벨업마다 `WEAPON / SKILL / ALLY`를 아우르는 세 개의 무작위 보상 중 하나를 선택해
   화력과 생존 방식을 바꿉니다. 공격 스킬은 같은 선택을 반복하면 마스터 단계로 진화합니다.
5. 빌드와 조준에 따라 약 28~40초 안에 고정 물량 300기를 모두 처치하면 전장이 잠기고,
   2초의 보스 진입 연출 뒤 `THE WRONG ENGINE`이 출현합니다.
6. 범위·궤도·진행 방향이 미리 보이는 다중 패턴을 피하고, 패턴 종료 후 노출되는 약점에
   화력을 집중해 보스를 쓰러뜨립니다.

적을 처치하고 XP를 빨아들이는 순간의 연쇄 반응, 짧은 간격의 빌드 선택, 일반전과 보스전의
뚜렷한 리듬 전환을 한 판 안에 압축했습니다. 모든 적의 수는 정해져 있어 남은 수가 0이 되는
순간이 곧 보스전 진입 조건입니다.

## 빌드 선택

- `WEAPON`: 기본 자동 사격을 확장하거나 새로운 투사체·궤도 공격을 추가합니다.
- `SKILL`: 공격 속도, 피해량, 다중 발사, 보호막, 대시, 회복처럼 전투 규칙을 강화합니다.
- `ALLY`: 드론, 센트리 등 독립적으로 적을 추적하고 화력을 보조하는 동료를 배치합니다.

매 선택은 전투를 멈춘 상태에서 세 장의 카드로 제시됩니다. 같은 런에서도 단일 대상 폭딜,
광역 정리, 동료 중심 빌드처럼 서로 다른 조합을 만들 수 있습니다.

공격 스킬에는 적 무리를 연결하는 `ARC CASCADE`, 플레이어 주변을 쓸어내는
`ZERO-POINT NOVA`, 적 밀집 지점에 포화 폭격을 호출하는 `SKYFALL SUPPORT`, 조준한 한 줄을
관통하는 `OMEGA LASER`가 포함됩니다. 공중 폭격과 레이저는 긴 재사용 시간을 가진 자동
필살기이며, HUD에서 다음 발동 시간을 확인할 수 있습니다. 공격 스킬의 최종 랭크에서는
범위·연타 수·빔 폭이 크게 확장되고 `MASTER EVOLUTION` 연출이 재생됩니다.

## 카메라와 미니맵

본 전투 화면은 전체 지도를 고정해서 보여주지 않고 플레이어를 따라가는 줌 카메라를
사용합니다. 화면 밖에서 접근하는 대규모 적은 우측 하단 미니맵에서 적색 군집으로 표시되고,
현재 보고 있는 범위도 사각 프레임으로 함께 나타납니다. 대규모 공세 직전에는 화면 테두리와
미니맵이 적색으로 점멸해 공격 방향을 미리 판단할 수 있습니다.

## 보스전

`THE WRONG ENGINE`은 방사형 탄막, 회전 스윕, 지연 폭발 지대, 확장 링, 단발 돌진과 연속
돌진 등 서로 다른
회피 판단을 요구하는 패턴을 이어서 사용합니다. 위험 지대는 실제 피해 전에 명확하게
텔레그래프됩니다. 돌진을 피해서 보스를 전장 경계에 충돌시키면 3초간 코어가 노출되고 실제
피해가 2배로 증가합니다. 대시에는 기본 0.46초의 무적 페이즈가 있어 맵 전체를 통과하는
확장 링을 정면으로 가로지를 수 있습니다. 연속 돌진은 매 회 짧게 플레이어 위치를 다시
조준하므로 방향을 바꾸며 페이즈 대시를 아껴 쓰는 것이 핵심 전략입니다.

전투 중 `F`를 누르면 과거 4개 전선의 AEGIS ECHO, ROOK, NYX, MOSS가 12초간 소환되어 각자의
펄스·산탄·연쇄 번개·중화기로 자동 전투를 지원합니다. 호출에는 30초의 재사용 시간이 있으며
일반 물량전과 보스전 모두에서 사용할 수 있습니다.

## 조작

- `WASD` / 방향키: 이동
- `Space`: 0.46초 무적 페이즈 대시
- `F`: 4-FRONT RECALL 동료 4인 호출
- 마우스 또는 트랙패드 포인터 이동: 조준
- 기본 공격: 포인터 방향으로 항상 자동 발사
- 레벨업 카드 클릭 또는 숫자키 `1–3`: 보상 선택

별도의 사격 버튼은 없습니다. 포인터 버튼을 누르지 않아도 기본 공격이 계속 발사됩니다.

## 전용 전장과 에셋

게임은 이번 런을 위해 제작한 `public/assets/survivor/swarm-arena.png` 전장을 사용합니다.
넓고 막힘없는 원형 중앙부, 네 개의 진입 램프, 시안 동심원 전투선과 적색 위험 외곽이 실제
플레이 공간을 그대로 보여주며, 충돌을 유발할 수 있는 대형 구조물은 이동 가능 경계 밖에만
배치했습니다.

플레이어, 적, 보스, 드론과 설치형 장비는 `public/assets/survivor/` 아래의 프로젝트 원본
이미지를 재사용합니다. 런타임 이미지는 표시 크기에 맞춰 최적화하고, 고해상도 제작 원본은
`reference/source-assets/`에 보존합니다. 자세한 생성 도구, 프롬프트와 라이선스는
[`CREDITS.md`](./CREDITS.md)에 기록되어 있습니다.

## 성능

대규모 적 수에서도 저사양 브라우저가 버틸 수 있도록 렌더링 품질을
`CINEMATIC / BALANCED / PERFORMANCE`로 자동 조절합니다. DPR에 더해 내부 렌더 해상도를
단계적으로 축소해 CSS 표시 크기보다 불필요하게 큰 프레임버퍼를 만들지 않으며, 렌더 주기·파티클 및 동시
효과음 수를 품질별로 제한하고, 화면 밖 오브젝트를 생략하며, 정적 배경과 반복 효과를
캐시합니다. 프레임마다 생성하던 렌더 임시 배열·Set·그라디언트도 재사용합니다. 시뮬레이션은 렌더링 주기와 분리해 품질 단계가 내려가도 조작과 판정이 동일하게
유지됩니다.

## 로컬 실행과 검증

```bash
npm install
npm run dev
```

```bash
npm test
npm run build
npm run test:sites
```

게임 로직은 브라우저에서 로컬로 실행되며 플레이를 위한 API 키나 별도 서버가 필요하지
않습니다. Sites 패키징 구조를 유지해 build 결과에 `dist/client/index.html`,
`dist/server/index.js`, `dist/.openai/hosting.json`이 생성됩니다.

## 오디오

사격, 적 처치, XP 흡수, 레벨업, 대시, 위험 경보와 보스 패턴 효과음은 외부 음원 파일 없이
`src/audio/sfx.js`의 Web Audio 합성으로 생성하는 프로젝트 원본입니다. 메인 배경음악은
사용자가 제공한 `public/assets/audio/overload-main-theme.mp3`를 사용하며, 시작 버튼을 누르면
약 59.9초 트랙이 반복 재생됩니다. 우측 상단 사운드 버튼은 배경음악과 효과음을 함께
음소거하거나 다시 켭니다.
