- 플레이 가능한 전투원은 기본 **AEGIS**, 01구역 해금 **MIKA**, 03구역 해금 **VESPER**, 04구역 해금 **NOX**의 4명입니다. 현재 활성 포트레이트는 `survivor-portrait-v2.webp`, `mika-portrait-v2.webp`, `vesper-portrait-v7.webp`, `nox-portrait-v1.webp`이며 이전 시안은 제작 이력으로만 보존합니다. 잠긴 전투원도 정보 화면에서 일러스트·역할·해금 조건을 확인할 수 있지만 출격·태그에는 사용할 수 없습니다.
- 캠페인은 01—06의 지역별 4,096×4,096 정사각형 전장을 사용합니다. 360도 이동을 지원하며 다음 웨이브는 전진 좌표가 아니라 **현재 웨이브 전멸**로만 시작합니다. 8방향 전송 게이트, 지역별 미니맵과 증거물 좌표가 같은 월드 계약을 공유합니다.
- 새 전투원은 캐릭터별 `Q` 액티브만 사용할 수 있습니다. 전투원 정보의 시각적 스킬 노드에서 성장 조건을 달성해 `E`→`F`→`R`을 차례로 해금합니다. 잠긴 입력은 쿨타임을 소비하지 않으며 HANA 연구·ILYA 장비 개조와 중복되는 피해/내구도/속도 영구 강화는 전투원 동기화에서 제거합니다. 구버전 AEGIS 3개 강화선은 구매 랭크 합을 최대 3등급 스킬 링크로 이관하고, 기존 누적 소비 코어에서 새 링크 동일 등급 비용을 뺀 차액만 한 번 환급합니다. `aegis-skill-link`가 있으면 재이관·재환급하지 않습니다.
- 해금된 전투원이 둘 이상이면 `T`/모바일 TAG로 다음 전투원과 교대합니다. 교대 순간에는 얼굴 중심의 전용 사이드 컷인이 짧게 나타나고, 캐릭터별 쿨타임 은행은 독립적으로 보존됩니다.
- 비행선 조종사 **SERA**의 메뉴는 출격 화면을 복제하지 않고 `선행 정찰 지원`, `긴급 보급 지원`, `요격기 엄호 지원` 중 하나를 고르는 **항공 지원 전술**입니다. 대화창과 NPC 카드의 인물은 모두 같은 반실사 상반신 규격을 사용합니다. 연구실·정비소·항공 지원 전술 상세 화면의 좌측 일러스트만 하단에 고정되며 클릭 시 전용 반응 대사를 재생합니다.
- 로비 캐릭터는 승인된 **정적 원본 일러스트**를 사용합니다. 낮은 완성도의 Live2D/Cubism 프록시와 의존성은 활성 런타임에서 제거됐습니다. 설정 메뉴는 마스터/BGM/SFX 음량, 화면·성능, 조작·접근성 옵션을 제공합니다.
- 방어 작전은 별도 결정론 엔진·PC/모바일 전장·절차 합성 SFX를 사용합니다. 캠페인 전투와 같은 음량 설정을 따르며 설치·강화·선택 취소·웨이브·피격·파괴·승패 피드백을 구분합니다.

상세 소개·기획·AI 활용과 검증 범위는 [`AI·게임 개발 포트폴리오`](./docs/project/portfolio-ko.md)에도 통합해 관리합니다.

`HUMAN OVERRIDE: OVERLOAD`는 고도로 발달한 통치 AI `SOVEREIGN`이 세계와 인간의 선택권을
장악한 시대를 배경으로 합니다. 새 슬롯은 은발 돌격요원 AEGIS로 시작하며, 첫 구역의
`THE WRONG ENGINE`을 파괴하면 핑크 양갈래 기동요원 MIKA의 합류 시나리오와 태그 편성이
해금됩니다. 이후 전장에서는 한 번에 한 명만 직접 이동시키고 `T` 태그로 교대합니다.
포인터로 사격 방향을 조준하며 폐허가 된 수송로를 돌파합니다. 첫 작전에서 AI가 지휘하는
고정 물량 300기와 싸우며 ROOK·NYX·MOSS가 남긴 흔적을 발견하고 지역 추론핵
`THE WRONG ENGINE`을 파괴합니다. 이후 이동 기지 `HAVEN-09`로 귀환해 NPC와 대화하고,
비행선에서 `GLASS DUNE`과 `ABYSSAL ARCHIVE`를 포함한 01—03 내부망을 공략합니다. 세 구역을
모두 해방하면 SERA가 외곽 항로를 발견하고, 04—06 외곽 생산권역의 신규 군단·중간 보스·비원형
최종 보스가 이어집니다.

현재 실행 계층은 **Phaser 4.2.1 + TypeScript + Vite**로 구성됩니다. Phaser는 WebGL 전장,
씬 생명주기, 입력, 전진형 카메라, 스프라이트 풀, 보스 텔레그래프와 VFX를 담당하고, React는 인트로,
최소 HUD, 하단 시나리오 대화, 레벨업 선택과 결과 화면을 담당합니다. 전투 규칙은 Phaser 오브젝트와
분리된 결정론적 시뮬레이션으로 유지해 렌더 품질 단계가 바뀌어도 판정이 달라지지 않습니다.

기획 의도, 대표 지역 encounter beats, KPI 정의와 외부 플레이테스트 양식은
[`전투 콘텐츠 기획 기준선`](./docs/project/content-design-baseline-ko.md)에 정리했습니다. 정적 경제와
가설 목표는 `npm run analyze:content`로 다시 산출할 수 있으며, 외부 테스트 전 수치를 실제 플레이
성과로 표기하지 않습니다. 제출용 PDF는
[`HUMAN_OVERRIDE_OVERLOAD_Content_Design_Baseline_KO.pdf`](./output/pdf/HUMAN_OVERRIDE_OVERLOAD_Content_Design_Baseline_KO.pdf)입니다.

## HAVEN 타워 디펜스

메인 기지에서 전술 관제관 레아를 통해 별도의 `기지 방어` 서브 콘텐츠에 진입할 수 있습니다.
메인 출격보다 작은 보조 명령으로 표시되며, 세 개의 침공로와 열두 개의 방어 패드가 있는 전장에서
코어가 파괴되기 전에 모든 공세를 막습니다. 전투 중 획득하는 배치 자원으로 다음 네 방어 체계를
건설하고 3랭크까지 강화합니다.

- `펄스 센트리`: 빠른 단일 표적 요격
- `아크 릴레이`: 밀집한 적 사이를 잇는 연쇄 전격
- `스카이파이어 포대`: 장거리 착탄과 범위 폭발
- `이지스 바스티온`: 주변 적 감속과 광역 방어 펄스

`헤이븐 외곽선` 6웨이브, `중계망 정전` 8웨이브, `소버린 야간 공성` 10웨이브 순서로 난도가
상승합니다. 후반 공세일수록 소총수·저격수·거대 공성 병기가 함께 등장합니다. 첫 클리어와 반복
클리어 보상은 서로 다르며 연구 자료, 장비 부품, 증강 코어가 기존 캠페인 저장 슬롯에 누적됩니다.
각 단계는 헤이븐 외곽 갑판, 정전된 중계망, 적색 경보가 울리는 소버린 공성 갑판의 전용 가로·세로
배경과 서로 다른 세 경로·열두 패드 배치를 사용합니다. 적 좌표는 도로 중심선의 누적 길이를 따라
계산되므로 굽은 길에서 지름길로 이탈하지 않으며, 배경 도로와 패드도 같은 좌표 데이터에서 생성됩니다.
선택한 단계의 배경만 Phaser 부트에서 지연 로드해 다른 두 전장 이미지가 GPU 메모리에 함께 남지 않습니다.
저장 슬롯에서 `헤이븐 외곽선`에 처음 진입하면 전투를 멈춘 상태로 레아의 4단계 스포트라이트
가이드가 시작됩니다. 기지 내구도, 건설 패드, 포대별 역할, 공세 개시 버튼을 실제 인터페이스에서
차례로 강조하며, 완료하거나 건너뛴 기록은 슬롯에 저장되어 다음 도전부터 반복되지 않습니다.
전술 HUD는 기지 내구도를 최우선으로 표시하고 웨이브·현장 적·격파·배치 자원을 짧게 정리합니다.
PC는 1,280×720 전장을 유지하고, 세로 화면은 단순 축소가 아닌 720×1,280 전용 전장과 좌표 변환을
사용합니다. 기지 내구도와 전황은 상단 두 줄, 네 포대는 하단 한 줄, 강화·공세 명령은 safe area
안쪽에 고정되어 390×844 화면에서도 스크롤 없이 조작할 수 있습니다. 헌터·소총수·저격수·공성
워커는 역할별 6프레임 모션, 포대 탄도·연쇄 전격·박격 폭발·방벽 파동은 별도 6×4 VFX 아틀라스로
표시되며 격파 시 전용 파괴 프레임을 재생합니다. 디펜스 규칙은 `src/defense/engine.js`의 60 Hz
결정론적 시뮬레이션이 담당하고 Phaser는 전장과 스프라이트만 표시하므로 렌더 품질이 낮아져도
웨이브·피해·보상 판정은 유지됩니다.

## 한 판의 흐름

1. 새 저장 슬롯의 첫 출격에서는 HAVEN-09 관제관 RHEA가 레벨업 자동 빌드와 직접 사용하는
   Q/E/F/R 전술 회선을 실제 전투 캡처와 큰 핵심 문장으로 구분해 설명합니다. 출격 직후에는
   전투를 잠시 멈추고 실제 하단 Q/E/F/R 버튼을 차례로 밝히는 스포트라이트 안내가 이어집니다.
   브리핑과 실전 오버레이 완료 여부는 슬롯별로 독립 저장되고 브리핑은 기지에서 다시 볼 수 있습니다.
   브리핑 완료 또는 이후 출격 승인 뒤 01—03구역은 선택 지역의 NIGHTJAR 전용 영상을,
   04—06구역은 지역 포스터 전환을 표시합니다. 전환 화면 뒤에서는 선택 지역의 Phaser 인스턴스를
   숨김·일시정지 상태로 만들고 텍스처를 병렬 로드합니다. 영상 또는 포스터 전환과 런타임 준비가
   모두 끝나야 같은 인스턴스를 공개하므로 첫 프레임의 빈 캔버스와 중복 로딩이 없습니다.
   작전 브리핑 대화가 끝나면 플레이어는 폐허 수송로에서 교전합니다. 현재 웨이브를 전멸하면
   플레이어 좌표와 관계없이 다음 공세를 경고한 뒤 배치합니다. 이동만으로 살아 있는 적을 건너뛸 수는 없습니다. 모든 지역은 근접형 헌터 8기로
   시작하고 14→22→34→52→79→120→180→220기 순으로 공세 규모가 커지며 중반부터 소총수, 후반부터 저격수가
   합류합니다. 모든 증원은 경고
   뒤 맵 둘레의 SOVEREIGN 전송 게이트 8곳에서 순차 투입됩니다. 지나친 적도 제거되지 않으며,
   멀리 뒤처지면 사격 대기를 중단하고 가속 추격해 끝까지 살아 있는 전투 대상으로 남습니다.
2. 기본 무기는 포인터 방향으로 항상 자동 발사됩니다. 별도의 ON/OFF 또는 수동 발사 모드는
   없습니다. 펄스 소총 AEGIS는 EMP·방벽·항공 지원·회전 섬멸을 사용합니다. 빔 소드는 2구역
   `유리 사구` 보스를 처음 처치한 슬롯에서 해금되며, 해금 직후 전용 실전 교본이 한 번 열립니다.
   빔 소드 AEGIS는 6초 환검진·9초 유령 참격·15초 천검 영역·45초 거대 낙하검 필살기를 사용해
   기본기를 짧은 주기로 반복할 수 있습니다. MIKA로 태그하면 처음에는 단발·무관통
   링 블레이드로 싸우며, 레벨업의 `프리즘 링 동기화`를 5랭크까지 선택해야 쌍발·고속·다중 관통
   기본 공격으로 완성됩니다. 프리즘 연무·리본 와류·쌍성 질주·심장박동 카니발 Q/E/F/R 세트는
   기본 공격 증강과 독립적으로 유지됩니다. MIKA의 첫 SKILL 제안에는 4랭크 전용 성장인
   `PRISM TEMPO` 또는 `HEART GUARD`가 등장합니다. 전자는 링 블레이드 피해·관통과 적중 시 수동
   스킬 회전을 강화하고, 후자는 수동 스킬 적중으로 MIKA 전용 프리즘 보호막을 회복합니다.
   소총 전용 다중 사격·자동 폭격·오메가 레이저는 MIKA 보상 풀에 섞이지 않습니다.
3. 적이 떨어뜨린 XP를 모으면 시작 후 약 6~10초 안에 첫 보상 선택이 발생합니다.
4. 이후 빠르게 쌓인 레벨은 즉시 모달을 연속으로 띄우지 않고 하나의 `BATCH LEVEL` 선택으로
   압축됩니다. 최소 5.4초의 실제 전투 뒤 `WEAPON / SKILL / ALLY` 세 보상 중 하나를 골라
   여러 랭크를 한 번에 얻고, 남은 초과 레벨은 화력·내구 보너스로 전환됩니다.
5. 처치 진행률 48%·72%·88%에서 공격 속도와 피해량이 단계적으로 폭증하는 오버드라이브가
   해제됩니다. 72% 이후에는 전용 중장갑 이족 공성 워커가 후반 공세에 합류해 거대 포탄을

## 카메라와 최소 HUD

본 전투 화면은 수평 이동량에 맞춰 폐허 수송로가 계속 스크롤되고, 줌 카메라는 일반전과

카메라 중심과 조준 좌표는 AEGIS를 기준으로 함께 보정됩니다. 화면 우측의 전술 미니맵은
플레이어, 화면 밖을 포함한 살아 있는 적의 제한 표본과 활성 전송 게이트를 점으로
표시하고 불필요한 설명 문구는 제거했습니다. 상단 대형 헤더와 캔버스 밖 텔레메트리 레일은
복원하지 않습니다.
화면 안에는 체력, 목적지 진행률 또는 보스 체력, 남은 적, XP, 대시·Q/E/F/R 액티브와 최소 경로
안내만 남기고 대규모 공세와 보스 변이 정보는 짧은 한국어 경고로만 표시합니다.

일반전은 지역별 4,096×4,096 정사각형 월드에서 360도 이동하며, 독립 보스방은
1,920×1,080을 사용합니다. 적은 실제 피격 반경보다 큰 아트 실루엣 크기를 기준으로 재사용 공간
해시에서 서로 밀려나며, 전송 게이트의 8기 편대도 넓은 2열 배치로 물질화합니다. 따라서 최대 압력에서도
여러 적이 한 장처럼 겹치지 않습니다. 진행률을 별도 배경 카운터가 아닌 AEGIS의 실제 월드 좌표로 계산해
초반 우측 이동만 두 배로 빨랐다가 경계에서 느려지는 현상과 장거리 탄도가 잘리는 현상을 제거했습니다.
각 구역은 기존 대표 배경 뒤에 전용 확장 섹터를 이어 붙여, 25,000 유닛의 긴 이동 중 같은 그림이
계속 반복되지 않습니다. 확장 섹터는 중앙 72%를 넓은 전투로로 비워 대형 편대의 분리 간격과
배경의 실제 이동 가능 영역이 일치하며, PERFORMANCE에서는 동일 구도의 960×540 파생본만 로드합니다.
배경에서 낭떠러지·붕괴 잔해로 보이는 하단과 외곽은 실제 이동 경계에서도 차단해, 길로 보이지 않는
곳으로 캐릭터가 진입하는 시각·판정 불일치를 막습니다.
일반전에서 AEGIS는
74px, 헌터·서프레서·브루트는 각각 92·108·138px를 기준으로 표시되어 모든 적이 플레이어보다
크게 읽힙니다. 이동 중 자동 사격은 달리기 모션을 유지하고, 정지 사격은 준비·총구 프레임만
절제해 사용하며 방향 회전과 반동을 보간해 과도한 흔들림을 없앴습니다.

시나리오 대화 중에는 전투가 일시 정지되고 하단 패널에 현재 화자와 일치하는 상반신 일러스트가
크게 표시됩니다. AEGIS는 주인공 포트레이트, RHEA와 `OPERATOR`는 기존 RHEA 관제관
일러스트, HANA·ILYA·SERA는 각자의 전용 NPC 일러스트를 사용합니다. 대화창은 상반신과 확대된 본문을 분리 배치하고 NPC 일러스트 클릭 상호작용을 제공하지 않습니다. 지역 보스는
선택 지역의 3단계 형상 아틀라스에서 현재 단계를 골라 대사 패널이 열릴 때만 마운트합니다.
HAVEN-09 NPC 대화는 `Space`를 한 번 누를 때 한 줄씩 진행하고 마지막 줄에서는 대화를 닫으며,
`Esc`는 어느 줄에서든 즉시 닫습니다.
모바일 플레이는 세로 모드를 우선 지원합니다. 전투 화면의 버튼·대화창이 아닌 빈 곳을 누른 채
드래그하면 손가락을 댄 위치에 투명 원형 조이스틱이 나타납니다. 조금 밀면 천천히, 끝까지 밀면
최대 속도로 이동하며 대각선 속도는 정규화됩니다. 손가락을 떼거나 입력이 취소되면 즉시 정지합니다.
모바일에서는 가까운 생존 적을 자동 조준하고 자동 발사하므로 이동과 스킬 타이밍에 집중할 수 있습니다.
타이틀·저장 슬롯·기지·권역 지도·구역 상세·출격 준비도 세로 전용 레이아웃을 사용합니다. 제목과
본문을 데스크톱 축소판보다 크게 표시하고, 저장 슬롯은 한 열, 지역 상세는 한 장씩 넘기는 스냅 카드,
출격 승인은 하단 고정 대형 버튼으로 제공합니다. 전투는 검은 레터박스 없이 화면 전체 높이를 채우고
상단 목표/미니맵, 하단 체력/스킬 도크 사이를 실제 플레이 공간으로 사용합니다. 세로 전투 카메라는
표시 크기만 약간 확대하며 게임 규칙과 판정은 1280×720 결정론 시뮬레이션을 그대로 사용합니다.
타이틀은 WASD 대신 드래그 이동·자동 조준·하단 스킬 사용법을 안내하고, 구역 카드는 좌우 스와이프
안내를 표시합니다. 전투 우상단에는 48px 일시정지 버튼을 항상 제공하며, 세로 일시정지 메뉴는
줄바꿈 없는 한 열 버튼으로 구성합니다. 지원하는 터치 기기에서는 대시·태그·스킬·일시정지 입력에만
짧은 진동 피드백을 제공하고 진동 API가 없는 브라우저에서는 조용히 생략합니다.
기지 하단 명령은 모바일에서 두 개의 주요 명령과 한 줄 전체 폭 디펜스 명령으로 재배치하고,
출격 상세의 작전 정보와 해금 캐릭터는 한 열로 표시합니다. 한국어 제목·버튼은 음절 단위로
쪼개지지 않으며 하단 출격 승인은 중복 설명을 숨긴 전체 폭 버튼으로 유지됩니다. 상세창은 가로
카드의 스크롤 위치와 무관하게 모바일 안전 영역에 고정됩니다. 데스크톱은 별도의 fine-pointer
레이아웃을 사용해 창 높이가 낮아져도 모바일용 초소형 글꼴을 물려받지 않으며, 포인터 직접 조준과
가로 화면 지원을 그대로 유지합니다.

향후 Android/iOS 네이티브 패키징, 스토어 심사, 저장소·오디오·생명주기 어댑터 계획은
[`docs/mobile-app-release-roadmap.md`](docs/mobile-app-release-roadmap.md)에 정리했습니다.

## 보스전

`THE WRONG ENGINE`은 체력 70%와 38%에서 전용 이미지로 외형을 바꾸며, 장갑 전개형과
코어 멜트다운형으로 광폭화합니다. 변이 순간에는 반복 위험 경고와 충격파가 재생되고 잠시
피해가 차단되어 새 형상과 공격 단계가 확실히 드러납니다. 방사형 탄막, 회전 스윕, 지연
폭발 지대, 확장 링, 단발 돌진과 연속 돌진 등 서로 다른
회피 판단을 요구하는 패턴을 이어서 사용합니다. 위험 지대는 실제 피해 전에 명확하게
텔레그래프됩니다. 첫 지역 보스 체력은 560,000으로 완화해 초기 빌드도 세 단계와 여러 패턴을
충분히 보되 전투가 과도하게 늘어지지 않게 했습니다. 보스 본체에 직접 닿거나 돌진에 휘말리면 최대 체력의 약 44%에
해당하는 치명타를 받고 0.8초간 이동·대시·기본 공격이 정지합니다. 충돌 직후에는 플레이어를
보스 밖으로 밀어내고 재피격 유예를 적용해 억울한 연속 판정은 막습니다. 첫 지역 보스의 돌진을
피해 전장 경계에 충돌시키면 2.6초간 그로기에 빠지고 실제 받는 피해가 2.5배로 증가합니다.
대시에는 기본 0.46초의 무적 페이즈가 있어 맵 전체를 통과하는
확장 링을 정면으로 가로지를 수 있습니다. 연속 돌진은 매 회 짧게 플레이어 위치를 다시
조준하므로 방향을 바꾸며 페이즈 대시를 아껴 쓰는 것이 핵심 전략입니다.

내부망 세 보스의 공격 목록은 서로 겹치지 않습니다. `THE WRONG ENGINE`은 탄막·스윕·폭탄·링·단발 및
연속 돌진, `MIRROR TYRANT`는 `PRISM LATTICE / SOLAR FLARE / REFRACTION SWEEP /
MIRROR SHARDS`, `DROWNED ORACLE`은 `MEMORY SPIRAL / DEPTH COLLAPSE / ARCHIVE ECHO /
UNDERTOW`만 사용합니다. Phaser는 엔진의 동일 geometry 객체를 직접 그리므로 경고선,
애니메이션 진행, 끌어당김과 피해 판정이 서로 어긋나지 않습니다.
외곽 권역의 `FORGE COLOSSUS`, `TEMPEST WYRM`, `PALE ARCHON`도 각각 용광로·기상 방전·
생체 추적을 주제로 한 독립 패턴 집합과 비원형 보스 형상을 사용합니다.

피할 수 없는 광역기와 연속 돌진은 접촉 직전 정확히 1.5초 동안 화면이 흑백으로 변하고 전장이
16% 속도로 느려집니다. 이때 캐릭터 주변의 `SHIFT · 지금 패링`을 누르면 공격과 보스 탄을
튕겨내고 1.8초간 코어에 2배 피해를 줄 수 있습니다. 실패하면 공격이 그대로 적중합니다.
패링 대상 빈도는 체력 70%, 38% 이하에서 단계적으로 증가합니다. 또한 보스 체력 55%·30%·12%에는
전역 사이렌과 함께 시한폭탄 2·3·4개가 설치되고 각각 12·16·20초의 해제 시간이 주어집니다.
번호 순서 해제에 실패하면 9초 동안 보스 방어 회로가 켜져 받는 피해가 16%로 감소합니다.
캐릭터보다 큰 폭탄과 고대비 숫자 오버레이를 확인한 뒤 번호를 1부터
순서대로 클릭해야 하며, 다른 번호를 먼저 누르거나 시간이 끝나면 남은 폭탄이 즉시 전부 폭발합니다.

일반 전투는 지역별 4,096×4,096 정사각형 전장에서 진행됩니다. 플레이어는 360도로 이동하고,
다음 웨이브는 특정 X 좌표 도달이 아니라 현재 웨이브 전멸만으로 8방향 전송 게이트에서 연속
등장합니다. 미니맵·아군 흔적·상호작용 표시는 같은 월드 좌표 계약을 공유하며, 모든 적을
처치하기 전에는 보스방 배경을 불러오지 않습니다. 전멸 즉시 1.2초 워닝과 1.6초 당황 연출 동안
시간·이동·공격이 정지하고, 연출이 끝나면 일반 전장을 페이드아웃해 AEGIS와 보스를 서로 분리된
보스 챔버 시작 위치로 자동 재배치합니다. 입장 순간 카메라는 AEGIS를 정중앙에 유지하면서
1.08에서 0.78로 부드럽게 확장됩니다.
AEGIS는 64px로 축소되며 보스는 단계별 480·560·640px로 커져 접근할수록 화면을 압도합니다.

동료 빌드는 레벨업으로 선택한 드론·센트리가 지속 자동 전투하는 방식입니다. 과거의 일시적
4인 동료 호출은 제거했으며 `F`는 일반전과 보스전 모두에서 포인터를 관통하는 세 평행 항로의
`STRATOS RUN` 전투기 소사를 직접 호출합니다.

## 조작

- `WASD` / 방향키: 이동
- `Space`: 0.46초 무적 페이즈 대시
- `Shift`: 보스의 1.5초 패링 창에서 공격 반사
- `마우스 클릭`: 보스 시한폭탄을 표시 번호 순서대로 해제
- `Q` / `E` / `F` / `R`: 현재 전투원의 해금된 전용 수동 기술 · 새 전투원은 Q부터 시작
- `T`: 해금된 다음 전투원으로 태그 · 10초 · 얼굴 중심 사이드 컷인
- `Esc`: 일시정지 메뉴
- 데스크톱 마우스 또는 트랙패드 포인터 이동: 조준
- 모바일 세로 화면 빈 곳 터치 후 드래그: 플로팅 조이스틱 이동, 가까운 적 자동 조준
- 마우스 휠: AEGIS 중심 카메라 확대/기본 구도 복귀
- 기본 공격: 별도 키 없이 포인터 방향으로 상시 자동 발사
- 레벨업 카드 클릭 또는 숫자키 `1–3`: 보상 선택

## 전용 전장과 에셋

게임은 6개 지역마다 대표 루트·확장 섹터·보스 공간을 구분합니다. 첫 구역은
`public/assets/overload/environment/` 아래의 무너진 진입로, 침수된 추모 구간, 엔진 코즈웨이,
확장 반응로 구간과 전용 보스 챔버를 사용합니다. 나머지 지역은
`public/assets/overload/regions/{region-id}/` 아래의 독립 루트·확장 구간·보스 형상을 선택적으로
로드합니다. 대형 잔해와 가드레일은 실제 이동 경계 밖에만 배치됩니다.

보스 챔버는 1920×1080 전체 전장을 한 장으로 그린 고유 이미지입니다. 보스전에서는 타일 반복과
스크롤을 사용하지 않아, 좌측 격벽 입구·우측 상단의 파손된 거대 반응로·좌측 하단의 붕괴된
정비 갠트리·중앙 타원형 전투 바닥이 하나의 고정된 거대 공간으로 유지됩니다.

캠페인 화면은 `public/assets/overload/campaign/`의 `HAVEN-09` 기지와 비행선 지역 지도를
사용합니다. HANA·ILYA·SERA는 `public/assets/overload/ui/npcs/` 아래의 전용 포트레이트를
사용하고, 상세 시설 화면에서는 카드 프레임 밖 좌측 하단에 큰 일러스트로 배치합니다. 관제관 RHEA는 기존 별도 상반신
일러스트로 대화하고 첫 출격 수동 기술 브리핑을 맡습니다. 시나리오의 `OPERATOR` 표기도 같은
RHEA 일러스트에 연결됩니다. 기지 로비에서는 현재 편성 전투원을 중앙에 크게 표시하고 네 NPC는
좌측 시설 메뉴에서 호출하며, 대화를 열었을 때만 각자의 큰 상반신 일러스트를 사용합니다. 첫 지역의
아군 흔적은 `squad-traces-atlas.png`로 표시됩니다. 후속 5개 지역은
`public/assets/overload/regions/` 아래에 각각 독립된 루트·확장 섹터·적 형상·보스 형상을
가집니다. Phaser 부트 로더는 공통 전투 자산과 현재 선택한 지역의 일반 전장만 등록하며 다른
지역의 대형 배경·보스 아틀라스는 요청하지 않습니다.
선택 지역의 보스방과 3단계 폼도 해당 지역의 전멸·필수 흔적·중간 보스 조건을 마친 뒤 자동 워닝·당황 전환이 시작될 때 별도 로드됩니다.
챕터 1에서만 쓰는 동료 흔적 아틀라스 역시 후속 지역에서는 생성·로드하지 않습니다.

적 자폭 드론·소총수·저격수는 역할별 6×4/24프레임 모션 시트를 사용합니다. 동료 헌터 드론·
펄스 센트리·억제 드론은 유닛별 5×4/20프레임 시트를 해당 보상을 실제 획득했을 때만 로드합니다.
내부망의 THE WRONG ENGINE·MIRROR TYRANT·DROWNED ORACLE은 지역별 6×4/24프레임 시트로 단계별
대기·예고·공격과 변신·코어 노출·붕괴를 재생하며, 선택 지역의 자동 클리어 전환 전에는 메모리에
올리지 않습니다. 외곽 권역은 각 지역의 전용 3단계 보스 형상과 적군 시트를 사용합니다. 모든
시트는 정적 역할 이미지와 단계 폼을 로드 실패 폴백으로 유지합니다.

시작 화면은 사용자 제공 은발 AEGIS 키 아트를 전체 화면 배경으로 사용하고, 제목·한 줄 목표·
시작 버튼·핵심 조작만 표시합니다. AEGIS는 사용자 제공 은발 장발 일러스트를 기준으로
제작한 `public/assets/overload/hero/survivor-directional-aim-atlas.png` 및 빔 소드 대응 시트의
8×8 방향·공격 아틀라스와 대사용 투명
상반신 포트레이트를 사용합니다. MIKA는 표시 크기 최적화된 전용 `mika-portrait-v2.webp`, 8방향
`mika-directional-aim-atlas.png`, 6×4 링 블레이드 VFX를 사용합니다. 플레이어·동료·인간형 적·드론·설치 장비·보스의 인게임 이미지는 모두 천장에
고정된 카메라에서 수직으로 내려다보는 90° 탑다운 시점으로 통일했습니다. AEGIS는 예외적으로
전체 이미지가 360° 회전하거나 좌우 반전되지 않습니다. 포인터 방향을 8방향으로 양자화해 아래쪽은
얼굴과 전면, 위쪽은 뒤통수와 후면, 좌우는 측면, 하단 대각은 전면 측면, 상단 대각은 후면 측면 행을 고릅니다.
AEGIS는 모든 프레임에서 소총 개머리판을 오른쪽 어깨 포켓에 견착하고 오른손은
방아쇠, 왼손은 전방 총열을 지지합니다. 대사창 포트레이트만 의도적으로 정면 상반신 일러스트를 유지합니다.

활성 방향 시트는 8개 나침반 방향을 각각 준비·이동 4프레임과 공격 4프레임으로 분리합니다.
클립 우선순위와 대시 잔상은 유지하되 실제 주인공 이미지는 회전값·반전값 0을 사용합니다. 각 방향 행마다
총구 위치를 지정해 총구 섬광·탄도 시작점과
소총 총열이 정확히 이어집니다. 이동 중에는 보행이 사격 반동보다 우선해 상체가 과도하게
흔들리지 않습니다.

일반 전투 HUD는 화면 중앙 하단의 컴팩트 도크에 현재/최대 체력을 크게 표시하고, 피해를 받으면
체력바가 짧게 점멸·맥동해 위험을 알립니다. 그 아래에는 SPACE 대시와 Q/E/F/R 수동 스킬을
직관적인 그림 아이콘으로 배치하고, 아이콘 위 입력 키와 시계 방향 원형 쿨다운 마스크를 겹칩니다.
상태·팝업·목표·보스 이름은 한국어를 우선하며 필요한 고유명만 병기합니다. 모바일 세로
화면은 상단 전황·미니맵, 하단 체력·스킬, 어디서든 시작되는 플로팅 조이스틱을 위한 독립 배치를
사용합니다. 가로 화면은 보조 호환 레이아웃으로 미니맵과 터치 조작을 가리지 않도록 도크를
좌측 상단으로 옮깁니다. 레벨업 자동
SKYFALL 좌표 확정 전면 문구는 한 작전에서 최초 1회만 표시하지만 후속 자동 폭격의 실제 VFX와
효과음은 계속 재생됩니다.

한국어 본문·대사·버튼은 네트워크 요청이 없는 시스템 서체 스택을 사용합니다. 우선순위는
`Pretendard Variable`, Pretendard, `Noto Sans KR`, `Apple SD Gothic Neo`,
`Malgun Gothic`/`맑은 고딕`, system-ui와 플랫폼 기본 sans입니다. 번들에 포함된 Rajdhani와
IBM Plex Mono는 Latin 서브셋만 로드하며, Rajdhani는 영문 로고·표제 장식에, IBM Plex Mono는
영문 텔레메트리·코드·키·숫자에만 제한합니다. 따라서 한국어 글리프는 해당 Latin 전용 서체를
거치지 않고 운영체제의 한국어 서체로 바로 표시됩니다.

통일된 적·동료·보스 에셋은 각각 `public/assets/overload/enemies/`, `allies/`, `boss/`에 있으며,
전용 피격 스파크, 적 폭발, 보스 장갑 파괴·단계 전환·최종 폭발 VFX를 실제 엔진 상태에 맞춰
재생합니다. VFX는 판정을 바꾸지 않으며 품질 단계별 동시 개수 제한을 적용합니다. 이동, 공격
예비동작, 발사, 반동, 대시, 피격·스턴 및 단계 변환을 실제 엔진 상태에 맞춰 재생합니다.
기본 펄스·산탄·레일·로켓은 단색 구체 대신 전용 병기 아틀라스를 사용하고, 머즐 플래시,
피격 스파크와 폭발은 같은 시각 언어로 표시합니다. 수동 F/R과 자동 SKYFALL·ARC·NOVA는
6×4, 64px 셀의 심플한 16-bit 도트 아틀라스를 사용하고, Q EMP 펄스와 E 방벽 전개는 각각
6×1, 192px 셀의 고해상도 전용 아틀라스로 시드·전개·최대 출력·소멸을 부드럽게 표현합니다.
도트 시트만 NEAREST 필터로 확대하며, 적 전송 게이트는 스킬이 아니므로 기존 고품질 6프레임
행을 별도 6×1 시트로 보존합니다.
자동 SKYFALL은 과거의 노란 원형 경고·충격파 폴백을 겹쳐 그리지 않고 조준 장치·낙하탄·폭발 모션만 표시하며,
자동 OMEGA LASER는 포구와 종단 충돌 모듈 사이를 실제 엔진 끝점에 맞춘 하나의 연속 다중 레이어
광선으로 그립니다. 정사각 빔 조각을 이어 붙이거나 포신·한 셀을 공격 거리만큼 늘리지 않습니다. 독립 수동 기술은
`vfx/pixel/manual-ability-pixel-atlas.png`, 자동 기술은
`vfx/pixel/automatic-skill-pixel-atlas.png`를 사용하고, 긴 범위는 셀을 늘이지 않고 엔진의
점선 원·캡슐 판정 기하로 보강합니다. 고해상도 EMP·방벽 시트는 각 0.84375MiB RGBA8이고,
나머지 반복 기술은 작은 도트 시트를 유지해 전투 공통 텍스처 예산 증가를 제한합니다.
보스방에 진입하면 공통 패턴 6×6, 지역 고유 패턴 6×4, 시한폭탄 6×2 도트 시트만 추가로
지연 로드합니다. 경고/발동 모듈과 12프레임 시한폭탄 모션은 NEAREST 필터를 사용하며, 폭탄 번호는
별도 Phaser 텍스트로 표시합니다. 실제 광선·원·캡슐·클릭 판정은 엔진이 계속 소유해 시각 경고와
피격 범위가 어긋나지 않습니다.
모든 레벨업 선택지는
무기·기술·동료의 역할을 즉시 구분할 수 있는 전용 일러스트 카드를 사용합니다.
런타임 이미지는 표시 크기에 맞춰 최적화하고, 고해상도 제작 원본은
`reference/source-assets/`에 보존합니다. 자세한 생성 도구, 프롬프트와 라이선스는
[`CREDITS.md`](./CREDITS.md)에 기록되어 있습니다.

## 성능

01—06구역의 300/1,000/1,000/1,100/1,150/1,200기 전투 모두 저사양 브라우저가 버틸 수 있도록 동시 활성 적은
최대 220기의 성장형 압력 상한으로 제한합니다. 초반은 근접형 8기뿐이며 완료한 웨이브·레벨·처치
수·경과 시간에 따라 상한이 증가합니다. 일반 적 체력은 기존 기준의 3배로 상향하고 체력바는
역할과 무관하게 하나의 붉은 색으로 통일했습니다. 렌더링 품질은
`CINEMATIC / BALANCED / PERFORMANCE`로 자동 조절합니다. CSS 기준 게임 좌표계는 계속
1280×720이지만 실제 WebGL 백킹 버퍼와 표시 주기는 각각 CINEMATIC 1280×720/60fps,
BALANCED 1050×590/45fps, PERFORMANCE 896×504/30fps로 제한합니다. 전투 시뮬레이션은
표시 주기와 독립된 결정론적 60Hz 고정 스텝을 유지하므로 품질 단계, 렌더 프레임 수 또는
해상도가 내려가도 이동·공격·보스 판정은 변하지 않습니다.

시작 시 PERFORMANCE가 선택되거나 터치 중심 모바일 전투·세로 디펜스 화면이면
`performance` 에셋 프로필을 해당 Phaser 인스턴스에 고정합니다. 모바일 표시 크기에서는
저메모리 아틀라스의 셀 해상도도 충분하므로 기기 CPU/GPU 등급이 높아도 불필요한 원본 텍스처
디코딩과 업로드를 피합니다. 이 프로필은 플레이어·적·동료·보스 모션, 일반/보스 전장, 흔적, 게이트와 일부
VFX의 저메모리 파생본을 원본과 동일한 texture key 및 atlas 행·열 계약으로 로드합니다.
실행 중 품질 governor가 바뀌어도 두 해상도의 아틀라스를 함께 올리지 않으며, 저메모리
아틀라스는 `scripts/build-performance-assets.py`가 프로젝트 원본을 PIL LANCZOS로 셀마다
독립 축소해 재현 가능하게 생성합니다. 외부 이미지와 ImageGen은 이 파생 과정에 사용하지
않습니다.

렌더 경로는 카메라 밖 배우·투사체·픽업·파티클·대미지 텍스트와 효과를 Phaser 오브젝트/Graphics
작업 전에 제외하고, PERFORMANCE에서는 배우 모션 샘플링과 장식 VFX 갱신 주기·광선 수·고스트·
텍스트·동시 효과 수를 더 낮춥니다. 단, 화면을 가로지르는 저격선과 보스 위험 패턴처럼 실제
판정과 연결된 텔레그래프, 체력/스킬 HUD와 경로 미니맵은 계속 갱신됩니다. 프레임마다 생성하던
렌더 임시 배열·Set과 적 탐색용 공간 버킷은 재사용합니다. 탭 blur/숨김 상태와 WebGL context
loss 동안 governor 표본을 정지·초기화하고, focus/visibility 복귀 또는 context restore 뒤에는
중단 프레임을 저성능 표본으로 오판하지 않고 안전하게 재개합니다.

React 쪽 이미지는 전체 전투 에셋을 한꺼번에 복제하지 않습니다. 대신 타이틀 원화는 HTML에서
우선 요청하고 디코딩이 끝날 때까지 전용 로딩 화면을 표시합니다. 이후 유휴 시간과 화면 전환을
이용해 다음에 필요한 기지/NPC/지도/가이드 DOM 이미지만 화면 단위로 미리 디코딩합니다. 전투 진입은
현재 전투원·해금된 태그 전투원·관제 대화 포트레이트만 기다리며, 레벨업 보상 이미지는 Phaser가
준비된 뒤 유휴 시간에 내려받아 첫 전투 프레임을 막지 않습니다.
Phaser 공통·수송로·보스 텍스처는 이 DOM 캐시에 넣지 않습니다. 사용자 제공 BGM은 계속
`preload="metadata"`로 길이 정보만 먼저 읽고 첫 사용자 제스처에서 재생합니다. 반면 01—03의
선택 출격 영상은 한 편만 `preload="metadata"`로 마운트하고, 재생과 동시에 숨겨진 Phaser 준비를 병렬화합니다.

동일 시드의 적 220기·투사체 620개 고정 부하를 120회 워밍업 뒤 1,200스텝씩 7회 실행한
결정론 엔진 중앙값은 280.969µs/step에서 98.599µs/step으로 감소했습니다(2.85×,
-64.9%). 최적화 전후 seeded fingerprint는 완전히 동일합니다.

초기 페이지는 Phaser를 modulepreload하지 않습니다. 구역 출격 영상이 시작될 때 동적 import와
선택 구역 전장 로딩을 영상 뒤의 정지된 Phaser 인스턴스에서 병렬 수행하고, 실제 로더 진행률을
출격 UI에 표시합니다. 영상과 런타임이 모두 준비되면 같은 인스턴스를 바로 공개하므로 빈 캔버스나
두 번째 텍스처 로딩이 없습니다. 이때 보스방 에셋은 여전히 군단 전멸 전까지 로드하지 않습니다.
Phaser 부트도 선택 구역과 AEGIS의 선택 무기, 실제 해금된 태그 전투원만 조합합니다. 새 슬롯의
01구역 펄스 소총 번들은 full 기준 32개/10.50MiB에서 26개/5.48MiB, performance 기준
32개/7.51MiB에서 26개/3.34MiB로 줄었습니다. 잠긴 전투원의 8방향 아틀라스와 VFX는 해금 전 GPU에 올라가지 않습니다.
기존 약 1.8MB 단일 런타임은 `phaser-vendor`(약 1,685kB raw / 381kB gzip), 시뮬레이션
(약 125kB), 뷰(약 94kB), 씬 런타임(약 44kB), 에셋 매니페스트(약 23kB) 청크로 분리됩니다.
React vendor도 별도 청크라 기지 UI 수정과 Phaser 엔진 캐시가 서로 독립적으로 갱신됩니다.

Edge WebGL/RTX 4060 Ti에서 240프레임씩 실제 계측한 결과, 적 220기·플레이어 투사체 620개
고정 부하의 단독 재현은 CINEMATIC 품질에서 scene/rAF/render-submit CPU P95
21.7/7.1/10.3ms, scene drop 0.4%였습니다. 8개 시나리오 연속 배치에서는 브라우저
스케줄러·품질 governor 변동으로 같은 데스크톱/812×375 부하가 PERFORMANCE로 내려가며
scene P95 28.5/30.7ms를 기록했지만, render-submit P95는 11.8/8.3ms였고 console/page
오류는 없었습니다. 두 도트 시트와 게이트 행의 RGBA8 합계는 1.594MiB이며,
TextureManager 중복 제거 디코딩 추정치는 전장 47.007MiB, WRONG ENGINE 보스방
63.530MiB, 다른 지역 보스방 53.273MiB입니다. 브라우저는 물리 VRAM 할당량과 GPU 완료
시간을 직접 공개하지 않으므로 이 값은 실제 로드된 Phaser 텍스처의 RGBA8 상한이며
Resource Timing과 분리해 기록합니다. 상세 연속 배치는
[`qa/runtime-profile-latest.md`](./qa/runtime-profile-latest.md), 단독 재현은
[`qa/runtime-profile-route-repeat.md`](./qa/runtime-profile-route-repeat.md)에 있습니다.

2코어/2GiB/DPR 2로 에뮬레이션한 최종 PERFORMANCE 프로필도 같은 Edge WebGL 환경에서
240프레임 재측정했습니다. 적 220기/투사체 620개 전장은 896×504/30fps를 유지하며
scene P95 36.0ms(30fps 의도 페이싱 포함), scene-update CPU P95 2.4ms,
render-submit CPU P95 3.1ms, scene drop 1.2%, console/page 오류 0개였습니다. 보스전은
scene P95 40.4ms, render-submit P95 1.1ms, drop 1.7%였습니다. 전장 Phaser RGBA8 추정치는
47.007MiB에서 18.031MiB로 61.6%, 루트 텍스처는 18.167MiB에서 4.542MiB로 75.0%
감소했고 이미지 전송 추정치는 7.964MiB에서 4.761MiB로 40.2% 감소했습니다. CPU ×4

1구역 오답 엔진 중앙로는 기존 `overload-main-theme.mp3`, 2구역 유리 사구는
`refraction-war-glass-dune.mp3`, 3구역 심해 기록고는
`memory-below-pressure-abyssal-archive.mp3`를 각각 metadata-only로 불러와 반복 재생합니다.
출격 영상 중에는 로비 음악을 멈추고 영상 종료 뒤 선택 지역 음악만 시작합니다.
음악 재생기는 화면과 독립적으로 유지됩니다. 로비·시설·지역 선택·항로 관제·방어전 선택은 같은 곡을 이어 재생하고 중간 로딩은 음원을 다시 불러오지 않습니다. 무음 화면과 영상에서는 재생 위치를 보존한 채 일시 정지하며, 다른 곡을 거친 뒤에도 같은 앱 실행 중에는 이전 위치부터 복원합니다. 마스터 사운드와 음량 변경도 곡을 초기화하지 않습니다.

캐릭터 대사는 텍스트와 화자별 일러스트로만 제공합니다. 브라우저 음성 합성·음성 복제는 계속
사용하지 않습니다. 활성 런타임의 탑재 AI 안내는 Google Cloud
`ko-KR-Chirp3-HD-Kore`로 합성한 AEGIS 펄스 소총 `F` 항공 지원과 `R` 섬멸 모드 정적 MP3만 사용합니다. 과거 Q/E 파일은 제작 이력으로 보존하지만 런타임 매니페스트에서 제외합니다. 이 음성 묶음은
현재 AEGIS 펄스 소총 세트 전용입니다. 전투 화면에 들어갈 때만 미리 불러오며,
Q EMP 펄스·E 방벽 전개·F 항공 지원·R 섬멸 모드가 실제로 성공한
`manualAbilityActivated` 이벤트에서만 재생합니다. 전체 사운드 토글을 따르고, 긴 필살기 안내를
낮은 우선순위 안내가 끊지 않습니다. 브라우저 런타임에는 Google 인증 정보나 네트워크 합성 코드가
없습니다. 빔 소드와 MIKA는 현재 전용 음원이 없어 잘못된 기술명을 읽는 대신 무음으로 동작합니다.
재생성 절차는 `GOOGLE_TTS_SETUP.md`와 `scripts/generate-google-agent-voice.mjs`에 고정했습니다.

여성 캐릭터 피격 음성은 기술적으로 별도 보이스 버스와 3~5개의 짧은 변형을 연결할 수 있습니다.
다만 현재 저장소에는 사용자 제공 또는 사용 권리가 명확한 음성 원본이 없으므로 임의의 외부 음성은

하나·일리야·세라·레아의 대화 및 상세 화면은 `NpcPortraitImage`와 `npcPortraitFraming.js`의 공통 카메라를 사용한다. 승인된 768px 원본은 변경하지 않고 정수리·턱·얼굴 중심 기준으로 표시 비율을 정규화한다. 영입 화면은 일러스트와 실제 높이의 대화창을 같은 그리드에 배치하고, 모바일 기지 대화는 인물을 대화창 위에 연결한다. 연구실·장비고·항공 지원의 인물 표시를 확대하며 전투 대화와 레아 안내에도 같은 기준을 적용한다. 강화 기능과 대사 진행은 유지한다. 1440×960, 1024×768, 390×844, 844×390에서 관련 화면을 검수했고 집중 검사 19개 및 타입 검사를 통과했다. 이 항목은 로컬 수정 기록이며 기존 공개 배포 버전과 구분한다.

## 출격 편성과 작전 안내 개선 - 2026-09-06

현재 구역 출격은 해금된 전투원 중 1-2명을 선택한다. 첫 번째는 선봉, 두 번째는 교대 전투원이며 화면에서 선봉을 바꿀 수 있다. 두 명 선택 시 다른 전투원을 추가하려면 기존 선택을 해제한다. 태그는 선택한 두 명 사이에서만 번갈아 작동하고, 1명 출격 시 사용할 수 없다. 선택한 편성은 능력 안내, 출격 영상, 전투 진입과 결과 화면의 재출격까지 유지된다. 기존 태그 재사용 대기시간과 전투원별 능력 상태는 유지한다. 과거의 해금 전투원 전체 순환 설명은 이 규칙으로 대체한다.

작전 상세는 ‘적과 보스 공략 보기’로 개선했다. 일반 적 처치 목표와 중간 보스 유무, 최종 보스 이미지를 보여주며, 6개 구역의 적 구성과 위험한 공격, 대응 요령을 실제 전투 패턴에 맞는 한국어로 안내한다. 첫 클리어와 반복 보상은 유지한다. 보스 미리보기는 기존 애니메이션 시트의 첫 프레임만 표시한다.

전투원 일러스트는 클릭·대기·포인터 추적에서 머리만 따로 이동하거나 회전하지 않는다. 머리 클릭 대사와 표정 반응, 호흡, 머리카락 및 다른 부위의 반응은 유지한다. 이 변경은 기존 일러스트 연출의 조정이며 새로운 Cubism 리깅 완성을 의미하지 않는다.

검증: 관련 테스트 157개와 TypeScript 검사 통과. 브라우저에서 두 명 제한, 제외·교체·선봉 변경, 출격 인자와 데스크톱·모바일 배치를 확인했고, 실제 Phaser 전투에서 녹스·미카의 반복 태그 및 텍스처 로딩을 확인했다. 이 항목은 로컬 변경 기준이며 신규 배포를 뜻하지 않는다.

## 1구역 실시간 3D 전장 - 2026-09-06

오답 엔진 중앙로의 수송로와 보스방을 Three.js 0.185.1 기반 실시간 3D 환경으로 적용했다. 수송 레일, 철판 바닥, 매립 케이블·배수 격자, 냉각 탱크, 회전 터빈, 전력 중계기, 외곽 배기·변압 설비를 코드로 모델링했다. 별도 GLB나 외부 모델을 가져온 작업은 아니다. 기존 전투원·적·보스·스킬은 2D 표현을 유지한다. 고정된 직교 카메라의 지면 투영은 기존 전투 좌표와 일치하며, 이동·조준·태그 규칙은 결정론적 엔진이 관리한다. 이후 2-6구역 확장과 구조물 파괴가 추가되었으며 현재 규칙은 다음 절에 정리한다.

수송로의 독립 구조물 10개는 공통 원형 충돌 범위를 사용한다. 전투원은 구조물을 돌아 이동하며, 적도 우회한다. 빠른 이동과 양측 일반 탄환은 선분 충돌로 관통을 막는다. 광역·공중 스킬은 기존 영역 공격 규칙을 유지한다. 구조물 내부에 생성된 적·회복 키트·경험치 아이템은 바깥으로 보정한다. 구조물이 인물을 가리는 위치에서는 반투명하게 표시한다. 보스방 중앙은 기존 패턴의 회피 공간을 확보하기 위해 장애물 없이 유지한다. 미니맵과 출격 전 공략도 새 지형과 일치하도록 갱신했다.

최초 1구역 구현은 Three.js를 지연 로딩하고, Phaser가 확정한 카메라와 프레임에 맞춰 별도 WebGL 2 배경 캔버스를 그린다. 별도의 애니메이션 루프나 3D 물리 세계를 만들지 않는다. 고정 조명, 병합한 정적 메시, 접지 그림자와 품질별 렌더 해상도로 부하를 제한한다. 3D 초기화 실패 또는 컨텍스트 손실 시 기존 2D 배경과 같은 위치의 장애물 표시로 대체한다. 복구·리사이즈·종료 시 자원 정리를 검증했다.

검증: 지형·태그·전투·Phaser 관련 집중 테스트 129개 및 TypeScript 검사 통과. 브라우저에서 실제 로비 출격, 태그, 가림 처리, 390x844 세로 화면과 844x390 리사이즈, 보스방, 그래픽 컨텍스트 손실·복구, 종료 후 2구역 재진입을 확인했다. 실제 카메라의 지면 정렬 오차는 검수점에서 0.001px 미만이었다. 검수 프레임의 3D 추가 드로콜은 수송로 33-89회, 보스방 10회였다. 수치는 해당 화면의 브라우저 측정이며 실물 모바일 기기의 프레임 성능 보증이 아니다. 전체 프로덕션 빌드와 배포는 이번 작업에 포함하지 않았다.

## 전 구역 3D 전장과 구조물 파괴 - 2026-09-06

1구역에 이어 2-6구역의 일반 전장과 보스방에도 실시간 3D 환경을 적용했다. 전투원·적·보스·스킬은 기존 2D 표현을 사용한다. 지형은 Three.js 메시와 절차적 재질로 제작했다.

- 2구역 유리 사구: 모래 바닥, 수정 군집, 반사경 기둥과 외곽 사구.
- 3구역 심연 기록고: 매립 데이터 통로, 서버 설비, 기록 기둥과 침수된 외곽 설비.
- 4구역 네온 주조구: 격자로 덮인 용융 통로, 소형 용광로, 대형 프레스와 배기 설비.
- 5구역 폭풍 첨탑: 고가 갑판, 축전기, 코일 기둥과 회전하는 외곽 풍력 설비.
- 6구역 생체 금고: 육각 격실 바닥, 배양조, 생체 기둥과 외곽 격리 설비.

각 일반 전장은 서로 다른 배치의 구조물 10개를 갖는다. 냉각 탱크·수정 군집·낮은 서버·소형 용광로·축전기·배양조는 양측 일반 탄환과 검 공격으로 파괴할 수 있다. 피격 시 내구도 표시가 나타나고, 파괴되면 붕괴와 파편 연출 뒤 낮은 잔해가 남는다. 잔해는 이동과 사격을 막지 않는다. 대형 기둥과 프레스는 파괴되지 않으며, 보스방 내부는 회피 공간을 위해 비워 둔다. 다른 광역·공중 능력은 기존 공격 규칙을 따른다.

구조물 상태는 결정론적 전투 엔진이 관리하며, 파괴 즉시 충돌 목록·2D 대체 표시·미니맵에서 제거한다. 구조물 파괴는 적 처치 수, 경험치, 권역 진행도를 올리지 않는다. 새 출격에서는 설비 내구도가 복구된다. 작전 공략에도 파괴 가능한 설비와 우회할 구조물을 한국어로 설명한다. WebGL 2 장애 시 기존 배경과 같은 위치의 2D 충돌 표시로 전환한다.

검증: 관련 집중 테스트 168개와 TypeScript 검사 통과. 2-6구역 각각의 일반 전장·보스방, 실제 탄환에 의한 파괴, 지면 좌표 정렬, 그래픽 컨텍스트 손실·복구와 종료 후 캔버스 정리를 브라우저에서 확인했다. 6구역은 실제 앱의 출격·HUD·미니맵과 390x844 / 844x390 모바일 표시를 추가 확인했다. 지면 정렬 오차는 검수점에서 0.001px 미만이었다. 전체 캠페인 완주, 실물 모바일 성능 측정, 전체 프로덕션 빌드 및 신규 배포는 이 변경의 검증 범위에 포함하지 않았다. 로컬 서버에서 테스트할 수 있다.
