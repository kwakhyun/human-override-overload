# 애니메이션풍 초상화와 작전 기록

## 제작 범위

- 기존 캐릭터의 머리색·눈색·특징을 참고하고 의상과 자세를 새로 제작했다. 얼굴은 선화와 셀 채색의 애니메이션풍을 유지한다. 중간에 나온 반실사 얼굴 시안과 체크무늬 배경 시안은 사용하지 않는다.
- 전투원 4명과 NPC 4명의 상반신은 실제 알파가 있는 960×1280 PNG 원본과 WebP 런타임 파일을 갖는다. 머리·눈·팔 좌표와 공유 카메라를 새 캔버스에 맞췄다. 기존 전신용 Cubism 제작 입력은 별도 보관한다.
- 타이틀은 왼쪽 메뉴 공간을 남기고 오른쪽에 이지스와 하얀 AI 성채를 배치했다.
- 사용자가 승인한 배경 포함 시안 9장을 6개 에피소드에 연결했다. 새로 그린 상반신과 이전 시안의 의상이 다른 것은 장면·임무별 복장 차이이며, 한 이미지의 형태를 강제로 유지하지 않는다.

성채 그림은 추론핵의 시각화이며 새 플레이 구역을 뜻하지 않는다. 베스퍼 그림의 함대 역시 복원된 전술 모의 화면이다. 외곽 구역은 기존처럼 내부망 3구역 완료로 자동 해금되며, 세라의 선택 브리핑을 추가 잠금 조건으로 만들지 않는다.

## 저장 및 화면

`storyEpisodes.js`가 이미지·대사·열람 조건을 소유하고 `StoryScreens.jsx`가 공통 장면/기록 화면을 제공한다. `campaignSave.js`의 기존 `pendingPostVictorySteps`와 `storyFlags` 안에서 새 장면을 저장하므로 저장 버전과 서버 스키마는 바꾸지 않는다. 재접속 시 미완료 에피소드 처음부터 이어지며, 완료한 장면은 다시 자동 재생하지 않는다. 과거 슬롯에 프롤로그를 강제로 삽입하지 않는다.

후속 승리로 미완료 장면을 덮어쓰지 않는다. 순서에 맞는 완료만 큐에서 제거하고 완료/건너뛰기는 보상을 지급하지 않는다. 헤이븐의 **작전 기록**은 진행상 열람 가능한 장면을 다시 보여주고 저장 데이터·재화·출격 권한을 변경하지 않는다. 한 번의 입력으로 한 대사만 넘기며 길게 누르기와 중복 완료 콜백을 막는다. 다음 CG만 미리 읽고 전투 텍스처에는 추가하지 않는다.

## 재현 경로

- 내장 `image_gen`으로 제작. 모델 버전을 추정하거나 특정 버전 사용을 보장하지 않는다.
- 정확한 프롬프트, 원본 SHA-256, 원본/PNG/WebP 경로: `anime-2026-09-09.json`.
- 보관 입력: `reference/source-assets/overload/runtime-inputs/anime-2026-09-09/`.
- 이전 UI 이미지: `reference/source-assets/overload/runtime-inputs/pre-anime-2026-09-09/`.
- 사용자가 Python 후처리를 명시적으로 승인했다. `scripts/prepare-anime-art.py`는 초록색 매트 제거, 경계 탈색, 여백 추가, 축소·인코딩만 수행한다. 얼굴/의상을 Python으로 새로 그리지 않는다. Pillow와 NumPy가 필요하다.

```bash
python scripts/prepare-anime-art.py
```

## 검증

- 자동 검사 415개 통과: 신규/기존 슬롯, 장면 순서·재접속·중복 완료, 보상 보존, 열람 조건, RGBA 원본·WebP 형식, 머리 프레이밍과 모션 포함.
- 실제 Edge 브라우저: 새 슬롯 → 프롤로그 → 헤이븐, Space 길게 누르기, 기록 6편 끝까지 다시 보기, 전투원 4명 정보 및 모션, NPC 4명 대화. 다시 보기 전후 저장 문자열 동일, JavaScript 예외 0.
- 1440×900, 390×844, 844×390에서 화면 검수. 물리 모바일 장치의 성능 검증이나 전체 캠페인 실전 완주를 의미하지 않는다.
- 런타임 이미지/음원 소유권 검사: 누락 0, 미사용 0. 효과음·보스 수치·전투 판정은 이 변경 범위에 포함하지 않는다.

로컬 검수 이미지는 `qa/anime-2026-09-09/`에 있으며 제작 원본과 검수 자료는 공개 빌드에 포함하지 않는다.
