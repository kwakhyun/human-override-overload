## 적용 내용

| 영역 | 개선 |
| --- | --- |
| 전투원 | 미카·베스퍼·녹스를 이지스의 전투 시점에 맞춰 재제작. 8방향 8×8, 기본 128px/모바일 96px 셀과 하단 기준점을 유지. 이지스 두 무기 시트도 공통 여백으로 정규화. 미카는 원형 칼날, 베스퍼는 금색 정밀 사격, 녹스는 적색 무기를 유지. |
| 캐릭터 스킬 | 이지스 두 무기와 미카·베스퍼·녹스의 Q/E/F/R, 자동 스킬에 선명한 중심광과 부드러운 잔광을 적용. 큰 효과는 기본 256px/모바일 128px 셀. 공통·권역 보스 효과는 192px/128px. 다중 스킬의 가산 합성 밝기를 제한하여 캐릭터와 위험 표시를 덜 가린다. |
| 적과 보스 자세 | 발이 있는 인간형·보행형 적과 모든 보스는 조준 각도를 몸체 회전에 사용하지 않는다. 가로 방향 전환이 자연스러운 적은 좌우 반전하며 보행 메크와 중간보스는 자세를 고정한다. 명확한 항공기·드론만 방향 회전을 유지한다. 원화 기준이 북쪽인 비행체의 각도 오프셋도 반영했다. |
| 외곽 적 | 4~6구역은 기존 4칸 정지 시트를 6×4 이동·준비·공격·피격 시트로 교체했다. 행은 적의 종류, 열은 동작이며 중간보스는 마지막 행을 사용한다. |
| 보스 | 여섯 보스의 관절·장갑·발사·파괴 자세를 새로 제작했다. 1~3구역은 6×4 계약을 유지하고, 4~6구역은 8×4 런타임 시트를 추가했다. 외곽 보스는 입장할 때만 로드한다. |
| 일반 적 | 소총병·저격 포대·공성 워커의 금속 노이즈를 줄이고 외곽선과 장갑 면의 대비를 높였다. |
| 방어전 | 포탑의 상단 잘림·다음 셀 조각을 제거한 6×4 시트를 적용했다. 적은 네 방향별 두 이동 자세를 사용한다. 8개 특화 분기는 레일·노드·방호 링과 색으로 구분한다. 파괴 효과는 별도 기존 시트를 유지한다. |
| 동료·설치물 | 발이 있는 동료의 전체 회전을 제거하고 소형 동료/EMP의 표시 크기를 소폭 조정했다. 소환 상태의 보라색 전체 틴트를 제거해 고유 장비와 코어 색을 보존했다. 기존 드론·센트리 모션은 유지한다. |
| 재생성 | 기존 PERFORMANCE 도구의 베스퍼 0.5배 오류를 0.75배로 수정하고 녹스를 추가했다. 신규 시트는 하나의 recipe에서 두 품질을 생성하며 기존 PERFORMANCE 빌더도 같은 recipe를 읽는다. |

## 제작·검수 기준

- `scripts/sprite-quality-recipes.json`: 28개 주 시트, 총 916개 프레임 칸. 신규 생성 판 26개와 기존 이지스 두 시트의 정규화로 구성한다. EMP/방벽은 이지스 시트에서 두 개의 독립 행을 추출한다.
- 네온·폭풍 보스 원본은 요청한 8열 대신 실제 7열로 생성됐다. 실제 격자를 보존해 읽고 발사/전환의 일부 프레임을 홀드하여 8열에 배치했다. 32칸을 32개의 독립 생성 포즈라고 세지 않는다.
- 평탄화된 체크무늬 배경, 베스퍼의 잘못된 방향, 미카의 총기 오류가 있는 초안은 제외했다. 수정 생성 후 방향과 고유 무기를 확인했다.
- VFX의 원본 행 간격이 균등하지 않은 곳은 검수한 실제 `rowCuts`를 사용한다. 단순히 4등분하면 이전 행의 불꽃이 다음 행으로 섞이므로 이 경계를 recipe에 고정했다.
- 검은 효과 배경은 밝기를 알파로 분리하고 색을 역보정한다. 배우 원본은 크로마 배경을 제거하고 가장자리 색 번짐을 정리한다. 모든 축소는 셀별로 수행하며 4px 이상 안전 여백을 검사한다.
- 원본은 `reference/source-assets/overload/sprite-quality-v3/`, 최종 파일은 `public/assets/overload/quality-v3/`에 보존한다. 이전 원화 파일을 덮어쓰지 않는다.
- 정확한 생성 요청 원문: [제작 프롬프트](sprite-quality-prompts-2026-09-06.md). 원본 해시·출력 크기·셀 경계는 로컬 `qa/sprite-quality-v3/packing-report.json`에 기록한다.

## 확인한 범위

- TypeScript 검사와 방향·프레임 선택·기존 애니메이션·에셋 격자·품질별 로드·방어전·검 무기·패키징 관련 검사를 실행했다.
- 격리된 Edge에서 여섯 보스의 실제 Phaser 텍스처 로드와 고정 회전, 네 전투원의 네 스킬 발동/쿨다운/출력, 모바일 PERFORMANCE 로드, 방어전 4종 포탑/특화/이동 프레임을 확인했다. 이미지 요청 실패와 브라우저 스크립트 오류를 수집한다.
- 비교 페이지 `/tools/combat-sprite-review.html`에서 모든 신규 시트, 방향 선택, 밝은/어두운 배경과 두 품질을 확인할 수 있다. 이는 검수 도구이며 실제 전투 HUD가 아니다.
- 스크린샷·runtime-report는 `qa/sprite-quality-v3/`에 보존한다. 디버그/통제 장면에 대한 검수이며 여섯 구역 전체 클리어 또는 실물 모바일 기기 성능 측정을 의미하지 않는다.
- 기존 전투 규칙, 피격 반경, 피해량, 쿨다운, 이동/조준 및 BGM 수명은 변경하지 않았다. 셀 애니메이션 개선이며 새 Cubism 리깅을 완성했다는 뜻이 아니다.
