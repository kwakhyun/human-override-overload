# 공개 저장소와 게임 이미지

공개 GitHub 저장소에는 실행 소스, 에셋 경로·로딩 규칙, 문서와 승인된 게임 화면 스크린샷을 게시합니다. 게임용 독립 이미지와 제작 원본은 로컬 또는 별도 비공개 보관소에서 관리합니다.

## 제외 범위

- PNG·WebP·JPEG 등 게임 이미지, 스프라이트 아틀라스, PSD·CMO3·MOC3 등 편집·모델 파일
- `game/reference/`의 제작 입력 전체
- `game/public/assets/overload/live2d/`의 모델·텍스처·제작 메타데이터
- `game/output/`의 PDF 등 출력물: 원본 아틀라스가 문서에 포함될 수 있으므로 공개하지 않습니다.
- QA용 이미지와 문서 폴더에 복사된 독립 아틀라스

`game/scripts/public-asset-policy.json`에 나열한 32개 문서용 스크린샷과 사용자가 공개를 승인한 이지스 대표 아이콘 3종(512px WebP·32px PNG·180px PNG)이 이미지 예외입니다. 생성 원본은 비공개입니다. README의 7개 인게임 화면도 포함됩니다. 새 스크린샷은 실제 UI를 포함한 소개 화면인지 검토한 뒤 이 목록과 `.gitignore` 예외를 함께 수정합니다. 승인된 대표 아이콘 외의 원본 그림이나 아틀라스를 스크린샷·아이콘 이름으로 바꾸어 게시하지 않습니다. 음원·출격 영상의 추적 범위는 이 이미지 분리 작업에서 변경하지 않습니다.

## 개발 환경

공개 저장소를 새로 복제하면 게임 이미지가 없습니다. 실행·빌드·에셋 의존 테스트 전에 권한 있는 비공개 사본에서 런타임 이미지를 기존 `game/public/assets/` 경로에 복원해야 합니다. 이미지 재제작에는 `game/reference/` 입력도 필요합니다. 에셋 URL을 공개 GitHub raw 경로로 바꾸거나, Git LFS에 올려 우회하지 않습니다.

현재 개발 PC의 파일은 `git rm --cached`로 Git 추적만 해제했으며 디스크에서 삭제하지 않았습니다. 다른 기존 체크아웃에서 이 삭제 커밋을 받기 전에는 그곳의 에셋을 별도 보관한 뒤 다시 로컬 경로에 복원합니다. 로컬 작업은 기존 에셋으로 계속 실행할 수 있습니다.

저장소 루트에서 로컬 Git 훅을 설치합니다. 기존 커스텀 훅 경로가 있는 환경은 덮어쓰지 말고 검사 명령을 기존 훅에 연결합니다.

```bash
git config --local core.hooksPath .githooks
cd game
npm run check:public-assets
npm run analyze:assets
```

`check:public-assets`는 Git 인덱스를 검사하고, pre-commit 훅은 이미지의 강제 추가도 차단합니다. pre-push 훅은 전송할 브랜치 끝과 새 커밋의 파일 추가를 검사하므로 이미지를 추가했다가 다음 커밋에서 지운 경우도 거부합니다. 훅은 로컬 설정이며 다른 체크아웃에는 자동 설치되지 않습니다.

게임 배포는 비공개 에셋을 복원한 로컬 환경에서 빌드한 산출물을 사용합니다. Git 추적 제외는 웹 게임에서의 이미지 제공을 막는 기능이 아닙니다. 이미지를 포함한 빌드 산출물을 공개 소스 저장소에 커밋하지 않습니다.

## 기존 Git 이력

이 정책은 최신 트리와 앞으로의 업로드를 대상으로 합니다. 이미 게시된 과거 커밋·태그의 이미지까지 삭제하려면 별도 이력 재작성과 강제 푸시가 필요합니다. 원격 캐시·포크·기존 복제본은 최신 트리에서 파일을 제외하는 것만으로 제거되지 않습니다. 이력 정리 전에는 새 브랜치나 새 원격으로 전체 기존 이력을 전송하는 작업도 훅에서 거부할 수 있습니다.
