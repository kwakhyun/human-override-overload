# 부위별 반응 대사 개편

로비의 “터치 상호작용” 안내 배지를 제거했다. 원화 960×1280 좌표에서 캐릭터별 자세를 기준으로 머리카락·얼굴·옷깃·양어깨·상체·양팔·양손·허리 장비의 11개 영역을 작성했다. 영역끼리 겹치지 않으며 이미지와 같은 배율·위치를 사용한다.

이지스는 무뚝뚝한 배려, 미카는 가벼운 장난과 활기, 베스퍼는 여유 있고 절제된 말투, 녹스는 정중한 단문과 건조한 유머를 중심으로 부위당 두 줄씩 총 88줄을 새로 작성했다. 상체 접촉에는 자연스러운 거리 요청을 사용하며, 거절 뒤에 호감을 덧붙이는 기존 대사는 폐기했다. 전투 보고만 반복하지 않고 휴식·옷 정리·동료의 안부 등 기지 생활에 어울리는 소재를 섞었다.

`src/ui/portrait/portraitInteractions.js`가 좌표와 대사를 소유한다. 부위마다 순환 순서를 따로 유지해 다른 부위를 눌렀다고 첫 대사가 건너뛰어지지 않는다. `InteractivePortrait.jsx`가 로비와 전투원 정보 화면 모두에 5.2초 말풍선을 표시하며, 연속 클릭은 마지막 대사로 갱신하고 캐릭터 전환·화면 종료 시 타이머를 정리한다. 말풍선은 얼굴 아래에 표시되고 포인터 입력을 가로채지 않는다. 화면상의 안내 배지는 없지만 부위 버튼의 접근성 이름과 키보드 조작, 대사의 상태 알림은 유지한다.

기존 Cubism 컨트롤에 부위를 연결했으며 새 얼굴/손가락 리깅을 추가한 작업은 아니다. 전투와 저장 진행은 변경하지 않았다. 작업 시작 때 이미 수정되어 있던 AEGIS·MIKA·VESPER CMO3 파일은 이번 UI 변경에 포함하지 않았다.

검증: 421개 자동 테스트, TypeScript/프로덕션 빌드, 자산 누락/미소유 0. 격리된 브라우저에서 네 명의 11개 부위를 강제 클릭 없이 확인했고, 1440×900·390×844·844×390에서 말풍선과 모바일 얼굴 터치를 확인했다. 결과는 `qa/portrait-touch-2026-09-09/`에 있다.
