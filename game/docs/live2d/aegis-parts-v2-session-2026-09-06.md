# 이지스 Cubism 부위 리깅 v2 — 2026-09-06

현재 결과는 **제작 중인 독립 리깅 검수본**이다. 목표인 상용 인기 게임 수준의 표정·전신 동작·물리 완성본에 도달하지 않았으며 활성 게임에는 적용하지 않았다. 승인 원화와 네 전투원의 공통 표시 비율은 유지했다.

## 소재 보완

`scripts/prepare-aegis-rig-parts-v2.mjs`는 현재 승인된 `survivor-portrait-v2.webp`에서 24개 소재 레이어를 만든다. v1의 분리된 잔여 조각 레이어를 없애고 해당 부위로 배정했다. 앞머리/옆머리/얼굴 경계를 조정하고, 뒤쪽 소재에 4px 겹침을 확보했다. 총 32,912개의 겹침 픽셀과 8,674개의 가려진 얼굴 보완 픽셀이 있다.

얼굴 보완은 내장 ImageGen으로 새로 생성한 `head-underpaint-v2.png`에서 가져왔다. 생성물은 RGB 체크무늬 배경이므로 투명 원화로 취급하지 않았다. 원래 불투명한 머리카락 아래에 가려지는 얼굴 내부 픽셀만 사용했다. 원본 얼굴의 눈·입·비율은 중립 상태에서 대체하지 않는다. 요청 전문은 `aegis-head-underpaint-v2-prompt.txt`에 있다. 예전 거부된 리그/PSD와 v1에서 탈락한 보완 시안은 사용하지 않았다.

소재를 CPU에서 중립 합성한 원화 대비 채널 차이는 0이다. 이 수치는 Cubism의 필터링 결과나 움직이는 경계 전체의 예술적 품질 승인이 아니다. 머리카락 잔가닥의 부위 소속 및 가려진 의상면은 추가 원화 보완이 필요하다. 생성 스크립트 재실행은 출력 PSD/PNG를 덮어쓰므로 수작업 보정 원본을 먼저 보존해야 한다.

## 실제 Editor 작성 내용

Cubism Editor 5.3.04에서 PSD를 가져오고 직접 디포머/키폼을 편집했다. SDK 5.0 MOC3, 2048×2048 아틀라스, 원화 100% 배율, pixelsPerUnit 864, 모델 중심 0.5/0.5로 출력했다.

| 제어 | 실제 구조 및 범위 | 검증된 변형 |
| --- | --- | --- |
| `ParamBreath` 0/1 | `AEGIS_Breath_Body`, 워프 8×12 / 베지어 4×6 | 상체의 국소 호흡. 정수리와 다리는 고정. 팔꿈치 자식 계층도 호흡을 상속 |
| `ParamHairFront` -1/0/1 | `AEGIS_Fringe_Center_Sway`, 호흡 자식 | 중앙 앞머리 `Hair_Fringe_Center`만 독립 변형 |
| `ParamHairBack` -1/0/1 | `AEGIS_Hair_Back_L_Sway`, 호흡 자식 | 긴 뒷머리 `Hair_Back_ScreenL`만 독립 변형 |
| `ParamAegisElbowL` -30/0/30 | `AEGIS_Elbow_L`, 호흡 자식, 회전각 -0.5/0/+0.5도 | 화면 왼쪽 아래팔·소매 끝·손을 같은 관절 축으로 회전 |

팔꿈치는 빈 회전 디포머의 축을 원화 좌표 약 (236, 809)에 먼저 놓고, 인스펙터에서 세 메시를 자식으로 연결했다. 중립에서 원화를 이동하지 않았다. 위팔은 이 회전 디포머에 포함하지 않는다. 손목/손가락 개별 리깅은 아직 없다. 회전폭은 현 소재의 좁은 겹침 면에 맞춘 제한값이며 크게 늘리려면 숨은 관절면부터 추가해야 한다.

최대 단독 정점 변화는 중앙 앞머리 약 2.75px, 긴 뒷머리 약 3.68px, 팔꿈치 회전에 따른 손끝 약 5.54px다. 호흡의 가슴 최대 변형은 약 7.78px이며 검수 대기 상태에서는 78%만 사용한다. 팔꿈치 계층을 호흡 아래에 연결한 뒤에는 왼손도 호흡에 약 4.46px까지 반응한다. 기존 손 고정 설명은 v2의 팔꿈치 연결 이전 상태에만 해당한다.

## 브라우저 동작 및 검사

검수 URL: `http://localhost:4174/tools/cubism-parts-v2-review.html`.

실제 Cubism Core로 출력 MOC3를 읽는다. 호스트는 5.4초 호흡 주기(들이쉬기 2.1초/내쉬기 3.3초), 앞머리·뒷머리·왼팔의 서로 다른 감쇠 반응을 구동한다. 이것은 Editor의 `physics3.json` 제작 완료를 의미하지 않는다. 머리 터치는 머리카락, 화면 왼쪽 아래팔 터치는 팔, 그 외 터치는 복합 반응이다. 반복 클릭은 현재 위치를 유지한 채 속도에 반응을 더한다. 중립 복원, 원화 비교, 수동 슬라이더, OS 모션 최소화와 비활성 탭 정지를 제공한다.

`scripts/verify-cubism-parts-v2.mjs` 결과:

- 실제 ArtMesh 24개. 네 채널의 단독/복합 정점 변화 확인.
- 앞머리와 뒷머리 단독 입력 시 해당 메시 하나만 변형. 팔 입력 시 아래팔·소매 끝·손 세 메시만 변형.
- 잘못된 정점/UV 0. 중립 복원 정점 차이 0.
- 원화에서 5×5 이웃까지 완전 불투명한 내부 690,751픽셀 중 중립 알파가 240 미만인 픽셀 0.
- 호흡 0/0.78/1 × 팔 -1/+1의 6개 조합에서 팔꿈치 내부 4,225픽셀씩 검사: 알파 빈틈 0. 이는 해당 내부 영역의 검사이며 움직이는 전체 외곽선의 완성 판정은 아니다.
- 클릭 위치 연속성, 머리/팔 반응 분리, 복귀, OS 모션 최소화, 원화 비교 토글 통과. 브라우저 오류 0.
- 데스크톱/모바일 및 팔 양 끝 자세 캡처: `qa/cubism-parts-v2-2026-09-06/`. 상세 수치는 `report.json`.

최소 범위의 검수만 수행했다. 활성 게임 로직을 바꾸지 않았으며 전체 테스트/배포 빌드는 수행하지 않았다.
