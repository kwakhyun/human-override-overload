# 프로젝트 정리 기록 · 2026-09-07

## 적용한 정리

Git에 기록된 미사용 파일 260개(기존 크기 합계 약 234.21MiB)를 제거했습니다. 이 수치는 경로만 옮긴 파일과 새로 생성한 QA·빌드 결과를 제외한 삭제 대상의 크기이며, 전체 디스크 사용량의 순감소 수치는 아닙니다. 과거 버전은 Git 이력에서 복원할 수 있습니다.

- 초기 게임 엔진·장비 규칙·Canvas 렌더러와 구형 swarm 렌더러, 그 프로토타입 전용 테스트 11개를 제거했습니다.
- 공개 폴더의 구형 일러스트·스킬·적·보스·NPC·배경·Q/E 음원을 정리했습니다. 공개 에셋은 293개에서 209개로, 약 167.50MiB에서 118.88MiB로 줄었습니다. 정리한 84개 중 78개는 삭제하고 6개는 필요한 제작·문서 입력으로 옮겼습니다.
- Git에 기록된 폐기 Cubism 시안·이전 검수 화면·생성기, 초기 프로토타입 자료, 중복 QA 이미지, 세션 인계 자료와 중간 AI 보고서를 제거했습니다. Git 미관리 파일의 제거 여부는 아래 제한을 따릅니다.
- AEGIS 원본 전투 아틀라스 두 장, AEGIS·MIKA 원본 일러스트, 비율 계약을 `reference/source-assets/overload/runtime-inputs/`로 옮겼습니다. 현행 Cubism v2가 쓰는 분리 좌표도 같은 폴더에 독립 보존했습니다.
- 전투 스프라이트 검수 화면과 메타데이터를 `public/tools/`에서 로컬 전용 `tools/`로 옮겼습니다.

## 코드와 문서 구조

- `src/ui/combat/ExpeditionCombatDock.jsx`가 체력·스킬·태그 표시를 담당하고 `App.jsx`는 화면 흐름과 입력 연결을 유지합니다. 게임 규칙·스킬 시간·배치는 바꾸지 않았습니다.
- 전체 구역이 쓰던 `src/render/sectorOne/`을 `src/render/environment/`로 옮기고 클래스 이름을 `RegionalEnvironment`로 통일했습니다. 낡은 `sectorOneTerrain.js` 호환 파일은 제거하고 현행 지형 모듈을 직접 사용합니다.
- `scripts/lib/runtime-assets.mjs`가 manifest의 동적 등록과 화질·방어전 변형, HTML 아이콘, 화면·스타일의 파일 참조를 함께 검사합니다. `npm run build`는 누락·미사용 공개 파일이 있으면 시작 단계에서 실패합니다.
- 저사양 이미지·음성 생성기에서 폐기된 출력 항목을 제거했습니다. 유지하는 정규화 도구의 보조 출력은 제작 입력 영역을 사용합니다.
- 채용 포트폴리오의 글꼴·레이아웃 도우미를 `scripts/lib/portfolio_pdf.py`로 분리했습니다. 폐기 보고서의 소스 문자열을 읽어 실행하던 의존성을 제거했습니다.
- 제출 문서에 필요한 실제 화면 이미지를 `docs/project/media/recruitment/`와 `content-planner/`로 옮겨 사용자 Temp와 임시 QA 파일에 대한 의존성을 없앴습니다. 기존 제출용 PDF와 문서용 근거는 보존했습니다.
- README는 현행 실행·규칙·구조·도구 안내로 통합했습니다. 상세 기획, 과거 측정 조건과 제작 프롬프트는 각각의 전문 문서와 CREDITS에 보존했습니다.
