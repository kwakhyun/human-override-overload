# TRAIN ME WRONG

플레이어의 강한 빌드를 분석하고 실제 카운터 웨이브를 만들어내는 적 AI에 맞서, 전투 중
전략을 계속 바꾸는 5분짜리 웹 서바이벌·전술 타워 디펜스 게임입니다.

게임 프로젝트는 [`game/`](./game)에 있습니다.

## 빠른 실행

```bash
cd game
npm install
npm run dev
```

검증:

```bash
cd game
npm test
npm run build
npm run test:sites
```

## 현재 구현 범위

- 5분 완결형 원형 아레나 런과 최종 보스
- 일반 적 1~2타 처치, 자동 조준, 관통·다중 사격·연쇄 전격·궤도 칼날·보조 드론
- 12종 레벨업 프로토콜과 3지선다 성장 선택
- 센트리와 EMP 파일런 배치 시스템
- 근접 헌터, 원거리 사수, 타워 해커, 중장갑 엘리트, 보스
- 피해원·이동량·타워 의존도를 읽는 브라우저 로컬 AI 분석
- 분석 결과가 실제 적 장갑과 구성에 반영되는 4종 카운터 프로토콜
- 신규 전장·플레이어·3종 적 이미지와 회전·가속·반동·대시 잔상 모션
- 외부 효과음 없이 Web Audio로 합성한 전투·건설·경보 사운드
- 인트로, 실시간 AI HUD, 레벨업, 보스, 승리/실패 결과 화면

배경음악은 추후 Suno AI에서 제작한 음원을 연결할 예정이며 현재 빌드에는 포함하지 않았습니다.
